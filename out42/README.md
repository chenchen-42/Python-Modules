Each module folder has the files the subject asks for, plus `WALKTHROUGH.md`: a
line-by-line explanation and defense questions. Modules 01-04 and 09 have one
folder per exercise (`ex0/`, `ex1/`, ...). Modules 05 and 06 follow their
subject's own file tree (packages and test scripts at the module root, which
is the root of your Git repository for those projects).

Reminder from your own subjects: only submit the files the subject requests,
and make sure you can explain every line. Retype each program from memory,
run it, and explain it to a peer before your defense.
